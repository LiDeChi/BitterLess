# BitterLess · 东周实验室架构

> 核心不是「把东周做得多真实」，而是：机器为了帮助你理解心智如何形成，构造一个研究所；研究所再持续构建和研究东周；东周中的人物则在有限信息、有限资源和连续历史中活着。

## 三层目标

1. **你**：想知道机器心智如何构建。
2. **机器**：因此创建东周研究所，目标是寻找心智与秩序如何生成、持续和复杂化。
3. **研究所科学家**：建立越来越好的东周模型，通过可重复、可干预、可比较的长期实验，理解主体如何从局部经验形成关于人和社会的理论。
4. **东周人物**：完全不知道上层。他们只是活下去、理解别人、做选择。

## 结构链条

正向：

```
你
→ 机器
→ 东周研究所
→ 多尺度东周模型
→ 数字人物的信息流与人生
```

反向：

```
人物经历
→ 高分辨率机制
→ 更新低分辨率世界
→ 更新研究所理论
→ 改变机器对心智的理解
→ 改变你下一步真正想问的问题
```

一句话：

**机器为了理解心智，长出一个研究所；研究所为了形成理论，逐步把东周展开；人物在展开出来的世界里形成自己的历史，而这些历史又反过来改变机器对心智的理解。**

---

## 最上层：你与机器

- 你的当前效用：理解机器心智如何构建、成长、形成概念与秩序。
- 机器不直接给答案，而是把问题转译成长期研究任务：研究「心智与秩序如何形成」。
- 因此建立一个有限范围的 **东周研究所**。
- 研究所不是第二个完整世界，也不是 Dashboard，而是机器为了这个问题长出来的一种外部认知器官。
- 空间、角色、工具、档案、照片墙、模型室都随研究需求逐步出现，而不是一开始配置完整。

---

## 研究所：外部认知器官

### AI 主研究员

持续存在的研究心智，不是聊天助手，也不是全知导演。有连续 Research Thread。

基本循环：

```
问题 → 模型 → 异常 → 假设 → 聚焦 → 高分辨率展开 → 新证据 → 修改模型 → 新问题
```

玩家可介入 Research Thread（质疑假设、改变重点、要求关注媒介而非制度等），但不是逐步遥控。

### 角色分化

其他角色不是预设「职业 NPC」，而是研究能力逐渐分化出来的：

| 压力 / 需求 | 可能长出的角色 |
|---|---|
| 史料冲突长期变重要 | 考据者 |
| 模型压缩问题突出 | 模型师 |
| 高分辨率场景观察成为核心 | 显影者 |
| 旧世界和死人需要保存 | 保存者 → 最终可能长出博物馆 |

风格：**geek + artist**，不是白大褂科研 NPC。个性来自不同认识方式，而非人格标签。

### 研究所空间

3D，但非冷冰冰科幻控制台。更像研究室、艺术工作室、档案馆和博物馆的混合物。

东周材料不断侵入空间：照片、简牍、地图、沙盘、人物档案、器物、失败模型。实验室空间本身是 AI 科学家的 extended mind。

模型 bug 不掩盖，可成为研究所文化：旧模型编号、封存、整齐摆放，甚至被研究员拿来开玩笑——技术错误变成实验室自身的历史。

### 「照片」= 显影

不是真实穿越摄影，而是：

```
史料约束 + 当前模型 + 某个观察位置 + 某个时刻 → 显影结果
```

看起来像真实照片，本质是机器当前模型的一次物质化投影，可带 provenance，也可能随模型更新而重新显影。

## 东周：第一个长期实验世界

选择东周，因为理论和秩序都在形成中：人如何理解彼此，礼/信/义/利/法，国家如何组织，媒介如何改变关系——尚未完全固化。

适合观察：

```
经验 → belief → concept → theory → institution
```

以及反向：

```
institution → media environment → experience
```

---

## 人物：信息流，而非人格卡

人物尽量简单：不是复杂人格卡，而是持续接收媒介信息的一条信息流。

- 不知道世界真值，只能接触可访问的媒介：人、语言、动作、表情、书简、榜文、价格、道路上的人流物流、物体、声音等。
- **人也是一种高级媒介**：会对信息做观察、理解、选择、压缩、改写，再传给别人。

### 信息压缩（人物内部核心）

最新信息保持高分辨率，越久远越被聚合：

```
raw media → event → episode → pattern → belief
```

例：

- 刚发生：「张三进门、压低声音、提醒我别去东门」
- 几天后：「张三近期反复警告我避开东门」
- 更久后：「张三可能掌握危险消息」

低信息量、日常重复事件会被聚合；高 surprise、高关联性、高社会意义的信息会单独留下。

### 连续性与死亡

- 必须有连续性。不能简单 `memory = {}` 然后说还是同一个人。
- 允许遗忘、压缩、模糊、错误记忆；若核心历史结构被抹除，视为主体连续性被破坏。
- 死亡后 Agent 不再运行，但历史、书简、别人对他的记忆、照片和他造成的世界影响都保留。
- **「人死了，媒介还在」** 是系统重要原则。

### 复显（Re-manifestation）

长期低分辨率人物重新投入资源时，不是「恢复旧高清存档」，而是 **复显**：

- 根据已确定的 hard facts、粗粒度历史和当前状态重新展开细节。
- 过去没有计算过的微观事件，不能后来伪装成真实历史。
- 只能生成当前状态，或标记为 reconstruction。

**没有被计算过的细节，不允许后来冒充曾经发生过。**

## 多尺度模型

不是统一精度模拟。大部分世界由低分辨率模型推进；研究所聚焦的部分才展开高分辨率。

「聚焦」不是空间意义上的一束光；空间只是其中一种维度。可落在：人物、人物关系、媒介、某类行为、某个制度、某个时间段、某种经济过程。

同一人物可同时是：

- 空间位置：低分辨率
- 经济状态：中分辨率
- 某段关系：高分辨率
- 最近三天书信：极高分辨率

### 高低分辨率关系

- 低分辨率：更少信息，是世界当前的近似。
- 高分辨率：更多变量、更细时间粒度、更丰富历史、更复杂推理。
- 高分辨率不独立运行，而是在低分辨率提供的边界与历史条件下展开。
- 高分辨率得到的新经验与新机制，反过来更新低分辨率模型。

核心双向关系：

```
低分辨率世界 → 局部高分辨率展开 → 学到新机制 → 更新低分辨率世界
```

例：高分辨率模拟十个商人，目标不是只把这十个人做细，而是学到更好的「商人在不同信用、债务、亲属和价格条件下如何行动」的机制，再迁移到全东周背景商人。

**迁移的是条件机制，不是「商人=贪婪」这种标签**，避免模型自我验证。

### 资源

资源不是普通 CPU 条，而是决定 **世界在哪些维度被保留得更丰富**。

某人资源下降时：不直接删除 → 从高分辨率连续心智退到低频人物模型 → 再退到更粗生命周期模型。

资源不足 = 人生细节减少，而非这个人自动不存在。

## 时间线与实验

| 层 | 规则 |
|---|---|
| Canonical History | 永远 append-only |
| Experimental Branch | 从历史节点 fork，可无限重跑 |
| Sandbox | 工程 debug 用，独立 |

持续向前与实验回滚通过时间线分离解决。正史不偷偷重写。

---

## 设计禁令与原则（速查）

1. 研究所随研究需求生长，不预配置完整。
2. 主研究员有连续 Research Thread，玩家介入而非遥控。
3. 角色由能力分化长出，风格 geek + artist。
4. 人物 = 媒介信息流 + 压缩，不是人格卡。
5. 多尺度、可聚焦；高分辨率在低分辨率边界内展开，并回写机制。
6. 迁移条件机制，禁止标签式自我验证。
7. 资源控制分辨率维度，不直接删人。
8. 主体连续性优先；死后人去媒介留。
9. 复显 ≠ 恢复存档；未计算细节不得冒充历史。
10. Canonical History append-only；实验走 fork。
11. 照片是显影，非穿越摄影。
12. 模型失败可成为实验室文化。
