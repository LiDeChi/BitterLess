目前这套“东周实验室”已经不是单纯的 AI 历史模拟器，而更像一个多层心智—模型—世界系统。它的核心不是“把东周做得多真实”，而是：**机器为了帮助你理解心智如何形成，构造一个研究所；研究所再持续构建和研究东周；东周中的人物则在有限信息、有限资源和连续历史中活着。**

最上层是你和机器。你的当前效用是“理解机器心智如何构建、成长、形成概念与秩序”。机器不会直接给一个答案，而是把这个问题转译成一个长期研究任务：研究“心智与秩序如何形成”。因此它建立一个有限范围的 **东周研究所**。研究所不是第二个完整世界，也不是 Dashboard，而是机器为了这个问题长出来的一种外部认知器官。它的空间、角色、工具、档案、照片墙、模型室都随着研究需求逐步出现，而不是一开始配置完整。

研究所内部的核心是一个持续存在的 AI 主研究员。他不是聊天助手，也不是全知导演，而是有连续 Research Thread 的研究心智。他不断做的是：观察现有模型哪里解释不好，找到异常，提出竞争假设，判断缺什么证据，再决定应该把东周的哪些模型提高分辨率。它的基本循环可以压成：

`问题 → 模型 → 异常 → 假设 → 聚焦 → 高分辨率展开 → 新证据 → 修改模型 → 新问题`

玩家可以介入这条 Research Thread，比如质疑它的假设、改变研究重点、要求关注媒介而不是制度，但不是逐步遥控它。

研究所里的其他角色不是预设好的“职业 NPC”，而是研究能力逐渐分化出来的。例如史料冲突长期变重要，才可能长出考据者；模型压缩问题越来越突出，才可能出现模型师；高分辨率场景观察成为核心，才可能出现显影者；越来越多旧世界和死人需要保存，才可能出现保存者，最后甚至长出博物馆。角色风格应该是 geek + artist，而不是白大褂科研 NPC：他们的个性来自不同认识方式，而不是人格标签。

东周则是研究所的第一个长期实验世界。选择东周不是因为“历史题材好看”，而因为它恰好处于一个理论和秩序都在形成中的时期。人与人如何理解彼此、什么是礼、信、义、利、法，国家如何组织，媒介如何改变关系，这些东西都还没有完全固化。因此它适合观察：

`经验 → belief → concept → theory → institution`

再反过来：

`institution → media environment → experience`

东周人物本身必须尽量简单。人物不是复杂人格卡，而是持续接收媒介信息的一条信息流。人物不知道世界真值，只能接触自己可访问的媒介：人、语言、动作、表情、书简、榜文、价格、道路上的人流物流、物体、声音等。人本身也是一种高级媒介，因为他会对信息做观察、理解、选择、压缩、改写，再传给别人。

人物内部最核心的是信息压缩。最新信息保持高分辨率，越久远越被聚合。可以理解成：

`raw media → event → episode → pattern → belief`

例如刚发生时保存“张三进门、压低声音、提醒我别去东门”，几天后可能压成“张三近期反复警告我避开东门”，更久以后压成“张三可能掌握危险消息”。低信息量、日常重复事件会被聚合，高 surprise、高关联性、高社会意义的信息会单独留下。

整个东周世界采用多尺度模型，而不是统一精度模拟。大部分世界长期由低分辨率模型推进；研究所聚焦的部分才展开高分辨率。这个“聚焦”不是空间意义上的一束光，空间只是其中一种维度。聚焦可以落在人物、人物关系、媒介、某类行为、某个制度、某个时间段或某种经济过程上。

所以同一个人物可以同时是：空间位置低分辨率、经济状态中分辨率、某段关系高分辨率、最近三天书信极高分辨率。

低分辨率模型保有更少信息，是整个世界当前的近似；高分辨率模型保有更多变量、更细时间粒度、更丰富历史、更复杂推理。高分辨率不是独立运行，而是在低分辨率模型提供的边界与历史条件下展开。同时，高分辨率运行得到的新经验和新机制又反过来更新低分辨率模型。

最核心的双向关系是：

`低分辨率世界 → 局部高分辨率展开 → 学到新机制 → 更新低分辨率世界`

所以高分辨率模拟十个商人，不只是把这十个人做细，而可能让实验室学到更好的“商人在不同信用、债务、亲属和价格条件下如何行动”的模型，然后迁移到全东周的大量背景商人。但迁移的是条件机制，不是“商人=贪婪”这种标签，避免模型自我验证。

资源玩法因此不是普通的 CPU 条。资源决定的是**世界在哪些维度被保留得更丰富**。某个人资源下降时，不直接删除，而是从高分辨率连续心智退到低频人物模型，再退到更粗的生命周期模型。资源不足意味着他的人生细节减少，而不是这个人自动不存在。

人物必须有连续性。不能简单 `memory = {}` 然后说还是同一个人。允许遗忘、压缩、模糊、错误记忆，但如果核心历史结构被抹除，就应该视为主体连续性被破坏。死亡以后 Agent 不再运行，但历史、书简、别人对他的记忆、照片和他造成的世界影响都保留。因此“人死了，媒介还在”是系统里很重要的一条。

当一个长期低分辨率人物重新被投入资源时，不是“恢复旧高清存档”，而是**复显**。系统根据已经确定的 hard facts、粗粒度历史和当前状态重新展开细节。过去没有计算过的微观事件不能后来伪装成真实历史，只能生成当前状态或标记为 reconstruction。换言之：

**没有被计算过的细节，不允许后来冒充曾经发生过。**

持续向前和实验回滚则通过时间线分离解决。Canonical History 永远 append-only；实验从历史节点 fork 出 Experimental Branch；工程 debug 使用独立 sandbox。实验可以无限重跑，但正史不偷偷重写。模型 bug 也不需要掩盖，可以成为研究所文化的一部分：旧模型编号、封存、整齐摆放，甚至被研究员拿来开玩笑，让技术错误变成实验室自身的历史。

研究所的空间是 3D 的，但不是冷冰冰的科幻控制台。它更像研究室、艺术工作室、档案馆和博物馆的混合物。东周材料会不断侵入这个空间：照片、简牍、地图、沙盘、人物档案、器物、失败模型。实验室空间本身就是 AI 科学家的 extended mind。

“照片”也不解释成真实穿越摄影，而是“显影”。照片是：

`史料约束 + 当前模型 + 某个观察位置 + 某个时刻 → 显影结果`

它看起来像真实照片，但本质上是机器当前模型的一次物质化投影，可以带 provenance，也可能随着模型更新而重新显影。这样既保留东周的视觉感，也避免硬穿越设定。

整个系统最深层的三层目标目前可以这样理解。

你想知道：**机器心智如何构建。**

机器因此创建东周研究所，目标是：**寻找心智与秩序如何生成、持续和复杂化。**

研究所里的科学家则有自己真正成立的使命：**建立越来越好的东周模型，通过可重复、可干预、可比较的长期实验理解主体如何从局部经验形成关于人和社会的理论。**

东周人物完全不知道这些。他们只是：**活下去、理解别人、做选择。**

最终整个结构是：

`你`
→ `机器`
→ `东周研究所`
→ `多尺度东周模型`
→ `数字人物的信息流与人生`

然后知识反向回来：

`人物经历`
→ `高分辨率机制`
→ `更新低分辨率世界`
→ `更新研究所理论`
→ `改变机器对心智的理解`
→ `改变你下一步真正想问的问题`

所以现在这套架构真正的核心已经不是“AI 模拟东周”，而是：

**机器为了理解心智，长出一个研究所；研究所为了形成理论，逐步把东周展开；人物在展开出来的世界里形成自己的历史，而这些历史又反过来改变机器对心智的理解。**
